A simple Flask-based micro project designed to store, manage, and display MCA subject notes.
This project demonstrates the basics of Flask routing, templates, file uploads, and CRUD operations.

Features:
Add and save note content, Upload files(PDF, images, etc), View saved notes, Organized folder structure, Simple HTML templates, Easy to run and lightweight.

Project Structure:
mca_note_app/
│── app.py
│── static/
│── templates/
│── uploads/
│── venv/

Purpose of the Project:
This mini project was made as part of the MCA Flask Micro Project requirement.
It helps students quickly store, view, and manage their study notes for easy access.
